# Autoescuela Aula 4 — San Vicente del Raspeig (Alicante)

Site institucional de alta conversão para a **Autoescuela Aula 4**, localizada na *C/ Ciudad Jardín, 2 Local 14 (Plaza Portabella)*, frente à parada do TRAM e junto à Universidad de Alicante.

## 📁 Estrutura do Projeto

- `index.html` — Página principal estática (HTML5 semântico, CSS3 editorial com variáveis e JS vanilla leve).
- `assets/` — Logotipo oficial, favicon, fotos da frota Volkswagen Polo, sala de aula teórica e alunos aprovados.
- `docs/` — Dossiê estratégico (`dossie_autoescola.md`) e dados originais (`dados.txt`), protegidos contra indexação via `robots.txt`.
- `vercel.json` — Headers de segurança HTTP (HSTS, X-Frame-Options, X-Content-Type-Options, Referrer-Policy, Permissions-Policy) e cache de assets.
- `.github/workflows/deploy.yml` — Pipeline automatizada de deploy para GitHub Pages com permissões mínimas (*Least Privilege*).
- `robots.txt` & `sitemap.xml` — Configurações de SEO.
